NEURO CHARACTER PIPELINE (All-in-One) — установка и запуск
===========================================================

Что это
-------
ОДИН аддон, в котором уже вшиты все движки конвейера:
  1) ComfyUI         — картинка персонажа (или эскиз -> рендер);
                       отдельная программа, аддон ходит к ней по HTTP
  2) Image to 3D     — картинка -> 3D-меш (движок вшит, модели качаются
                       при первом запуске, ~16-25 ГБ в ~/3DRedbox/ImageTo3D)
  3) Neuro-скелет    — скелет human.json внутри меша + автовесы
                       (+ опция Add fingers: 20 костей пальцев)
  4) X-Muscle System — мышцы на все кости, пришитые к коже (вшит)
  5) Pie Menu        — Ctrl+Alt+X над костями для ручной работы с мышцами
  6) neuro-анимация  — движение из neurosim (motion JSON)

Кнопки и подсказки: подписи по-английски, тултипы по-русски.

Установка (Blender 4.2+; для мышц нужен Blender 5.0+)
------------------------------------------------------
1) ВАЖНО: удалите старые раздельные аддоны, если они стояли:
   Image to 3D, X-Muscle System, X-Muscle Pie Menu
   (Preferences -> Add-ons -> найти -> Remove).
   Если забыли — при включении All-in-One сам их отключит и покажет
   предупреждение в карточке.
2) Edit -> Preferences -> Add-ons -> Install from Disk
   -> выбрать neuro_character_pipeline.zip
3) Включить галочку Neuro Character Pipeline (одну!).
4) Открыть 3D-вьюпорт -> клавиша N -> вкладка "NCP" (короткое название,
   раньше была "Neuro"). Резервный интерфейс: Properties -> вкладка
   Scene -> панель "Neuro Character Pipeline" — там FULL CYCLE, даже
   если вкладку N-панели не видно за другими аддонами.

PYTHON И АВТОЗАПУСК COMFYUI (новое в 2.1.0)
--------------------------------------------
В панели NCP -> Files & Settings теперь есть:
- ComfyUI URL и Output dir — хранятся в Preferences, больше не слетают;
- ComfyUI folder — папка ComfyUI (где лежит main.py);
- Python (ComfyUI) — путь к python.exe, в портативной сборке это
  <ComfyUI>\python_embeded\python.exe;
- кнопка Start ComfyUI — сама запускает ComfyUI на указанном порту
  (лог: <Output dir>\comfyui_console.log). Если ComfyUI уже отвечает —
  ничего не делает.
Всё то же самое есть в Preferences -> Add-ons -> Neuro Character Pipeline.

ЧТО НОВОГО В 2.6.0 (скелет без рук / ступни вбок / короткие ноги — окончательный фикс)
--------------------------------------------------------------------------------------
По вашему скриншоту (rot Z 89.87, план biped без рук, носки вправо,
короткие ноги). Причина у всех трёх симптомов ОДНА: разбор тела
верил, что меш уже правильно повёрнут, и жёстко считал «лицо = +X,
бока = ±Y». Автоповорот ошибся (стопы не читались -> слепой +90,
меш встал боком) и каскад: руки ушли из сектора поиска, носки
развернулись вбок, бедро нашлось у колена. Что сделано:

- РАЗБОР ТЕПЕРЬ ИНВАРИАНТЕН К ПОВОРОТУ. Перед анализом тело
  канонизируется само: зеркальная плоскость ищется по оси
  разделения ног (пары кластеров стволов) с голосованием
  носки/лапы + голова; под каким бы углом ни стоял меш — носки,
  руки, крылья и хвост строятся по факту геометрии, а спека
  отображается обратно в мировые координаты. Ошибиться поворотом
  больше нельзя;
- СЛЕПЫЕ ПОВОРОТЫ ±90 УДАЛЕНЫ. Если лицо не читается — меш не
  крутится вообще, риг строится как есть, в статусе честно
  пишется «лицо не определено». Подсказка «Rot Z 180 и Build
  Skeleton снова» осталась только для случая, когда лицо реально
  не определено;
- РУКИ БОЛЬШЕ НЕ ПРОПАДАЮТ. Ширина торса меряется по поясу таза
  (руки туда не доходят), отсекатели ослаблены, зеркальная пара
  рука/рука классифицируется вместе (у птицы больше не бывает
  «рук 2, крыльев 1»). Если руки СЛИЛИСЬ с корпусом (A-pose
  впритык) и ни один фильтр их не выделил — двуногому добавляются
  цепочки рук по пропорциям человека, с пометкой в статусе;
- НОГИ ПОЛНОЙ ДЛИНЫ. Ствол ноги ищется НАД ступнёй, радиус хода и
  порог слияния берутся от чистого среза ствола (ступня и соседняя
  нога больше не раздувают их), слияние с телом — по трём
  признакам (масса/размах/увод центроида внутрь). Бедро больше не
  оказывается у колена;
- СТОПЫ: носок = среднее передних 15% точек стопы в кадре
  существа — направлен туда, куда реально смотрит персонаж;
- пальцы: растопыренная ладонь даёт геометрические пальцы,
  кулак/варежка — стандартные 5 веером (имена приведены к единой
  схеме fng_arm_L_std_1_1);

Тесты: человек в 4 ориентациях + произвольный yaw 37, T-pose /
A-pose / круглые стопы / большие стопы, quadruped, bird, dragon,
biped_tail — носки/лапы всегда вдоль лица, руки на месте, ноги
полной длины. ALL OK.

ЧТО НОВОГО В 2.5.0 (фиксы пальцев/поворота/падения Auto-Rig + статус без обрезки)
---------------------------------------------------------------------------------
По вашему скриншоту: скелет без пальцев, повернут на 90 градусов,
Auto-Rig "не удался" с нечитаемой ошибкой. Исправлено:
- T-POSE БОЛЬШЕ НЕ ПРЕВРАЩАЕТСЯ В КРЫЛАТОЕ СУЩЕСТВО. v2.4.0 мерил
  "тонкость" руки по вертикали: расправленные руки T-pose тонки по Z,
  как крылья, и классифицировались крыльями -> человек получал
  универсальный скелет без пальцев. Теперь рука/крыло различаются
  ПЛОСКОСТЬЮ СЕЧЕНИЯ в средней части конечности: у руки сечение
  круглое (предплечье), у крыла — плоская перепонка. T-pose человек
  снова распознаётся как человек: контракт 18 костей + мышцы +
  нейроанимация + 20 костей пальцев (Add fingers теперь включён
  по умолчанию);
- ПОВОРОТ К +X ТЕПЕРЬ ПРАВИЛЬНОГО ЗНАКА. Раньше двуногих крутили
  вслепую на +90 (мог встать лицом назад). Теперь направление лица
  определяется по носкам/пальцам лап (стопы смещены вперёд от оси
  ноги) — поворот применяется только если нужен и правильного знака;
  в статус-карточке пишется, что сделано. Смотрит назад — rot Z 180
  и Build Skeleton снова (как и раньше);
- AUTO-RIG БОЛЬШЕ НЕ ПАДАЕТ С «ДУБЛИКАТЫ ИМЁН». Ошибка
  "дубликаты имён костей: ['leg_L_upper']" (у вас обрезалась до
  "...per']") возникала, если плоскость симметрии сползала и обе
  ноги получали суффикс L. Стороны ног теперь назначаются
  устойчиво: пары по зеркалу, при сползшей плоскости — деление по
  медиане самих ног;
- ЦЕПИ РУК/КРЫЛЬЯ РАЗВОРАЧИВАЮТСЯ НАРУЖУ. В v2.4.0 ось цепи
  направлялась внутрь (к креплению), 4 станции слипались у плеча:
  кости рук/крыльев выглядели точками, пальцы не находились.
  Теперь кончик цепи доходит до кисти/края крыла;
- ЧЕЛОВЕЧЕСКИЙ КОНТРАКТ НЕ РОНЯЕТ AUTO-RIG: если тело распознано
  как человек, но подгонка 18 костей не сошлась — строится
  универсальный двуногий с причиной в статусе, а не вся сборка;
- СТАТУС-КАРТОВКА ПЕРЕНОСИТ ТЕКСТ. Длинные сообщения (причины
  ошибок Auto-Rig) больше не глушатся "..." посередине — причина
  падения теперь видна целиком;
- ПОДПИСИ В ПАНЕЛИ БЕЗ ОБРЕЗКИ: Rot X/Rot Z, Plan, Spec JSON —
  подсказки читаются в тултипах;
- ПРОМЕЖНОСТЬ НАХОДИТСЯ И У ТОЛСТЫХ БЁДЕР: тест «между ног пусто»
  заменён на поиск долины плотности — пики плотности у внутренних
  краёв бёдер больше не маскируют раздельные ноги.

ЧТО НОВОГО В 2.4.0 (Auto-Rig переписан с нуля: любые существа)
---------------------------------------------------------------
Прежний Auto-Rig умел только двуногих людей. Теперь конвейер наложения
костей написан заново (neuro_creature.py) и понимает план тела ЛЮБОГО
существа — по одним лишь вершинам меша:
- НОГИ: считаются кластеры у земли — 2 (человек, птица), 4 (собака,
  лошадь, дракон), 6 и больше (насекомоподобные); для каждой ноги
  строится цепочка верх/низ/стопа прямо по изгибу конечности (колено
  ищется как точка максимального отклонения пути от хорды);
- РУКИ и КРЫЛЬЯ: латеральные массы за габаритом торса различаются
  автоматически — крыло это тонкое и длинное, крепится за спиной, а
  у четвероногого любая латеральная пара считается крыльями; по крылу
  и руке строится цепочка из 3 звеньев;
- ПАЛЬЦЫ: в сечениях кисти/лапы/крыла считаются стойкие кластеры —
  если пальцы различимы (3-8), для каждого строится своя цепочка из
  2 костей; если рука слиплась в варежку — стандартные 5 пальцев
  веером (для рук);
- ХВОСТ: масса позади таза — цепочка 2-3 звеньев с утоньшением;
- ШЕЯ: если голова дальше 16% роста от верха торса — 2-3 шейных
  звена (дракон, лошадь), иначе голова сразу на грудь;
- ГОЛОВА: радиус по реальному объёму головы.
В панели (шаг 4) появился выбор Body plan: Auto (определить самому),
Human, Quadruped, Winged quadruped, Bird, Dragon. Человек (2 ноги,
без крыльев и хвоста) по-прежнему получает контракт 18 костей
human.json — мышцы X-Muscle и анимация neurosim работают как раньше.
Остальные планы получают универсальный скелет по существу; мышцы и
neurosim-анимация для них отключены (кнопки честно предупредят).
Статус-карточка после Build Skeleton показывает распознанный план:
"План: winged_quad — ног 4, рук 0, крыльев 2, хвост да, шея да (3
звена); костей 41". Show landmarks ставит маркеры во все найденные
точки (бедра, колени, ступни, крепления рук/крыльев, голову, хвост).
Ориентация тоже двухступенчатая: сначала меш поднимается (лежал на
спине), потом доворачивается продольной осью к +X — для четвероногих
знак определяется по положению головы. Если персонаж смотрит назад —
rot Z = 180 и Build Skeleton снова.

ЧТО НОВОГО В 2.3.1 (фикс: UnboundLocalError 'np' при Build Skeleton)
---------------------------------------------------------------------
Если при нажатии Build Skeleton выскакивало
"UnboundLocalError: cannot access local variable 'np'", виноват был
случайный повторный import numpy внутри функции нейро-авто-рига:
из-за него Python считал numpy несуществующим на первой же проверке,
и Auto-Rig падал У ВСЕХ, у кого включена галка Auto-Rig (она по
умолчанию включена). Исправлено:
- Auto-Rig снова работает: скелет подгоняется под тело (см. 2.3.0);
- подстраховка: если Auto-Rig упадёт по любой другой причине, аддон
  больше не роняет построение скелета, а пишет причину в статус-карточку
  и достраивает скелет старым режимом (меш под скелет 1.70 м);
- при откате меш больше не поворачивается дважды (раньше авто-поворот
  применялся и в Auto-Rig, и повторно в старом режиме).

Подготовка ComfyUI (шаги 1-2)
-----------------------------
1) В ComfyUI: Settings -> Dev mode -> включить.
2) Соберите workflow генерации персонажа (SDXL/Flux, что угодно).
3) Сохраните его: Save (API Format) -> файл workflow_api.json.
4) В панели: ComfyUI URL (обычно http://127.0.0.1:8188),
   Workflow (API) = этот файл, Prompt = описание персонажа.
   Промпт подставится в первую ноду CLIPTextEncode, негатив — во вторую.
5) Эскиз: кнопки New (чистый лист) -> Open in Krita (рисуете) ->
   Refine via ComfyUI (эскиз уйдёт в ноду LoadImage вашего workflow).

Первый запуск Image to 3D
-------------------------
Если движок ещё не ставился: кнопки Install Engine и Download Models
в блоке 3 (несколько ГБ).

КУДА КАЧАЮТСЯ МОДЕЛИ (папка движка):
- По умолчанию: ~/3DRedbox/ImageTo3D (C:\Users\<вы>\3DRedbox\ImageTo3D).
- Своя папка (любой диск): панель NCP -> Files & Settings ->
  блок Engine & Models Folder -> кнопка Choose Folder.
  Или: Preferences -> Add-ons -> Neuro Character Pipeline ->
  поле Engine & Models Folder.
- Папка хранится в Preferences Blender (не в сцене!) и переживает

- При первом включении аддон сам подхватит старую папку: и из json
  старого Image to 3D, и поиском готового движка по всем дискам
  (папка с файлом INSTALLED).
- ВАЖНО: это НЕ папка models ComfyUI — у движка свой venv и своя
  структура (env\, engine\, models\...), общая папка не подходит.

Обновление со старых версий (1.x / 2.0.0)
-----------------------------------------
1) Удалите/отключите ВСЕ старые копии: и отдельные аддоны
   (Image to 3D, X-Muscle System, X-Muscle Pie Menu), и старую копию
   самого Neuro Character Pipeline (Preferences -> Add-ons -> Remove).
2) Проверьте папку addons, чтобы не осталось двух копий одновременно:
   <addons>\neuro_character_pipeline  и  <addons>\character\neuro_character_pipeline
   — оставьте ОДНУ (лучше новую, установленную из zip).
3) Перезапустите Blender, установите новый zip, включите галочку.

Если вкладка "NCP" не появилась
-------------------------------
1) F3 (поиск оператора) -> набрать "env" -> запустить "Env Report".
   Отчёт запишется в C:\Users\<вы>\ncp_report.txt и откроется в
   Text Editor внутри Blender — пришлите его целиком.
2) В 3D-вьюпорте панель "Neuro Character" (NCP v...) рисуется ВСЕГДА
   и не зависит от остальных секций. Если видна только она —
   остальной интерфейс упал, и Env Report скажет, почему.
3) Откройте Window -> Toggle System Console (Windows) — аддон печатает
   туда причину (например, "часть классов не поднялась").
4) Почти всегда причина — вторая копия аддона с теми же классами или
   недовключённый старый Image to 3D. Удалите старые копии, перезапустите
   Blender, включите одну копию.
5) Если в панели видна красная строка "Вторая копия аддона? ..." —
   это оно: перезапуск Blender после удаления старых копий.
6) Проверить установку можно и скриптом ncp_doctor.py (Text Editor ->
   Open -> Run): он покажет, какая копия откуда загрузилась.

Полный цикл
-----------
Full Cycle: если картинка уже задана — начнёт с меша, иначе сначала
сгенерирует картинку в ComfyUI. Дальше сам: меш -> скелет -> мышцы.
Меш автоматически повернётся (Auto-orient): встанет ровно и посмотрит
туда же, куда скелет; если смотрит назад — Mesh rot Z = -90 и повторить.
Прогресс — в строке статуса. Ошибки останавливают конвейер с текстом.

Анимация
--------
1) В neurosim (blender_neuro) во время обучения/просмотра экспортируйте
   Motion JSON (или возьмите из outputs/).
2) Кнопка Import Neuro Motion -> выбрать JSON.
   Скелет NeuroCharacter получит кейфреймы; мышцы будут тянуться
   и дрожать по физике X-Muscle.
3) Кнопка Bake Muscles — запечь softbody-кэши (после анимации).

Частые проблемы
---------------
- "ComfyUI не отвечает" — запустите ComfyUI, проверьте URL/порт.
- "В workflow нет ноды LoadImage" — для эскиза нужен img2img-workflow.
- "Меш не появился" — смотрите статус в карточке Image to 3D.
- "Отключите старые раздельные аддоны" — в Preferences остались старые
  Image to 3D / X-Muscle System: удалите их (аддон сам их отключает,
  но папки лучше удалить совсем).
- "Кнопка Choose Folder ничего не делает" (было в 2.0.0) — исправлено
  в 2.0.1: папка движка теперь хранится в preferences мастер-аддона.
- Мышцы получились крошечными/огромными — это нормально для AUTOAIM:
  размер зависит от расстояния между костями (наш скелет ~1.7 м).
- Веса назначились плохо — уменьшите полигонаж (Faces) или почините
  меш (Merge by Distance) и повторите Build Skeleton.
