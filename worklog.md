## Task 5 — Морфология по референсу + GitHub (v10, эта сессия)
Референс: `reference/Qwen21_00002.png` (веера + соты + воронка).

1. **Сглаживание**: все маски переведены на smoothstep; финальный проход
   Blur Attribute по позиции (слайдер `Smooth`); Set Shade Smooth; плотная база 61.7k вершин.
2. **Веера**: 2-лепестковый паттерн `pow(cos2θ·0.5+0.5, Lobe Sharp)` → разлёт крыльев
   (`Fan Spread`), загиб кромки (`Fan Curl`), подъём зоны между веерами (`Gap Rise` —
   глубокий V-вырез), рваная кромка (рябь синусом складок).
3. **Ровные дырочки**: шахматная 3D-решётка ячеек, у каждой ячейки свой радиус/глубина
   (псевдослучай из координат ячейки), профиль ямки — smoothstep; маски: соты на основании
   (крупные, редеют к талии) и мелкие дырочки у кромок вееров. Слайдеры Enable/Spacing/
   Radius/Depth/Var/TopRadius.
4. **Слот Cutter Object**: Group Input → Object Info → Transform (`Cutter Scale`) →
   Mesh Boolean (Difference) — можно перетащить свой объект-резак.
5. **Слот Extra Object**: произвольная геометрия присоединяется Join'ом в начале цепочки
   и деформируется вместе с кораллом.
6. **Ловушки Blender 5.3 beta** (найдено и обойдено):
   - GN-нода Solidify УДАЛЕНА → толщина кромки заложена в профиль (заворот внутрь);
   - у Vector Math 4 входа: Scale — inputs[3] (float), inputs[2] — посторонний вектор;
   - LENGTH/DISTANCE отдают скаляр из векторного сокета → при чтении в Math молча 0.5 →
     длина/дистанция считаны чистой float-математикой (sqrt по компонентам);
   - дефолтная сцена factory-startup содержит куб → чистится перед сборкой;
   - `modifier[key]` (ID-свойства) не читаются → значения слайдеров не печатаются, только пишутся.
7. **Бисект цепочки**: env `CORAL_STAGE=twist|wobble|pleats|lobes|holes|blur|bool` —
   обрезает дерево до стадии (так ловился взрыв bbox ±0.5 за стадию).
8. **Диагностика**: bbox до/после модификатора: base ±0.626/h1.548 → mod ±1.165/h1.800.
9. **Проверка 5.3 vs 5.4**: тот же скрипт без правок на Blender 5.4.0 Alpha даёт
   побайтово тот же bbox и идентичный рендер → версия вторична, решает параметризация.
10. **GitHub**: репозиторий `evikass/blender_stroika`, залиты исходники, рендеры, blend.
